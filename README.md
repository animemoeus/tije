# tije

Transjakarta routes and live buses on a map, live at https://tije.info. Now you can watch your bus not come instead of just waiting for it.

No APBN money went into this, and it isn't a Proyek Strategis Nasional, so it might actually get finished. No forest was cleared for a sawit plantation to build it either, although Prabowo did point out that palm trees have leaves too, so apparently that would have been fine. Bus late? Skip the Jokowi-style blusukan to the halte and check the map. Makan bergizi gratis not included.

## Run it

```bash
npm install
npm run dev   # http://localhost:3000
```
